Несколько небольших правок

Подсвеченные слова показывают, что изменилось

СОГЛАСОВАНИЕ

Мы хотел → Мы хотели

С местоимением «мы» нужна форма «хотели».

ОРФОГРАФИЯ И ПУНКТУАЦИЯ

пожалуйсто → пожалуйста

«Пожалуйста» пишется через «а» и выделяется запятыми.

УПРАВЛЕНИЕ

обсудить о шагах → обсудить шаги

После «обсудить» предлог «о» не нужен.
